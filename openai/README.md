# Kolena Agents for ChatGPT and Codex

Build or improve your [Kolena](https://www.kolena.com) Agents from ChatGPT or Codex, run documents through them, and
review what they found.

A Kolena Agent is a reusable document-processing workflow. Its Prompts read the documents you send and produce typed
results.

## Use it

Ask ChatGPT or Codex to find an Agent, send documents to it, follow processing, and report the results with links back
to Kolena. You can also ask it to design an Agent's Prompts from your business requirements, diagnose wrong Results, or
improve an existing Agent using representative Runs.

Creating Runs and re-running Prompts consume Kolena credits.

## Requirements

You need a Kolena account with MCP access enabled. Sign in to Kolena when the client prompts you. The plugin acts with
your own permissions.

## Data

The plugin connects to Kolena at `https://agents-api.kolena.com/mcp`. Documents and results are retained under your
Organization's Kolena data retention policy.
